# 结果图指标色阶按本批结果每列独立归一化

结果图里延迟、抖动、丢包、下载、上传各指标列的颜色深浅，以**本批测速结果中该列自己的最小值和最大值**为端点：最小值最浅、最大值最深，方向按指标好坏（速度越大越深，延迟/抖动/丢包越小越深）。

各列互不干扰：上传列的色阶端点只统计上传自己的值，不吸收下载列更大的值——否则上传的颜色永远被下载的最大速度稀释，分不出层次。慢速批次同理受益：一批全是 0.5~2MB/s 的节点，2MB/s 就是最深，而不是被全局标准压成浅色。

两个口径：速度、延迟、抖动为 0 表示没测出来，不进统计（失败行按最浅处理）；丢包率 0% 是有效值，正常参加。本批全部同值时分不出差异，整列填最深。
