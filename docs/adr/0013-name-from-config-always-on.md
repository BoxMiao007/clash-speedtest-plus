# 「产物跟随文件名」写死为开启，删除界面开关与命令行 flag

ADR-0011 引入「产物跟随文件名」时留了双入口：界面开关默认开、命令行 `-name-from-config` 默认关。实际使用中两个事实让「可选」失去意义：界面上几乎没有人会去关掉它（关掉只是让产物更难对上源），开关常年占着选项栏一行；命令行与界面默认值不一致，同一份配置双击和脚本调出来的产物名不一样。

从本 ADR 起「产物跟随文件名」成为恒定行为：

- 界面选项栏删掉该开关项，不再有可切换的状态；
- 命令行 `-name-from-config` flag 删除，老脚本传它会直接报 unknown flag 而不是静默改变行为（fail-fast）；
- 命名规则本身不变：配置轮基名替换/插在产物名前，订阅源轮没有可跟的文件名仍保持默认命名，产物序号（ADR-0012）照旧。

替代方案是保留 flag 并改成默认开——但那会静默改变所有不传该 flag 的老脚本的产物命名，不如删掉报错来得诚实。
