# 多源分别测速：每个源一整轮，串行自动推进

勾选多个配置、或配置与订阅混着测时，不再把所有源合并去重测一轮、出一张图：每个源（勾选的每个配置文件、每条订阅）各自一整轮测速，各自出结果图和输出配置，轮与轮串行自动推进，不停顿确认。命令行 `-c` 传多源同一规则——「不要混合」是行为纠正，不是选源界面独有的开关。

每轮独立重建测速器、结果通道和界面，独立应用全部选项；图顶来源行和摘要计数只算当轮。测速界面状态行标「第 X/N 轮」加当轮源名；还有后续轮时本轮测完、产物保存完自动退出进下一轮，最后一轮照旧停在界面等退出键。

选源路径测到中途按 Esc：中断本轮（不写本轮产物）、剩余轮全部作废，回选源界面改完重排；已完成轮的产物保留。某源解析出 0 个节点（拉取失败、空配置）时提示并跳过该轮，不废掉队列；订阅解不出 Clash 格式、yaml 损坏仍报错终止（fail-fast，用户需要换 UA 或改地址）。

选源界面路径下订阅在「获取」阶段已写成临时文件，队列里的值是本地路径——订阅轮的判定靠源结构自带的标记，不靠路径是不是 http 开头；临时文件基名不进任何产物命名。
