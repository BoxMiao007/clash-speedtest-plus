# ADR-0022：单测行固定与高亮、折叠窄栏重做、徽标对齐

- 状态：已接受
- 日期：2026-10-30
- 关联：[ADR-0020](0020-merged-test-view.md)（合并视图）、[ADR-0021](0021-entry-badge-menu-detail.md)（徽标与单独测试）、[规格 0001](../specs/0001-viva-gui.md)

## 背景

按试用截图继续修三处：

1. 用「单独测试此节点」测速时，结果到达后该行被按速度重排抽走，同时没有任何「正在操作哪一行」的视觉提示。
2. 侧边栏折叠后的窄栏很难看：56px 里顶左一张「展开」按钮和小字「来源」，余下是大片空白与边框。
3. 软/硬路径徽标的文字没有在底色里居中，宽度也被撑得偏大；底色太浅，和白色背景区分不明显。

## 决策

1. **单测行固定 + 高亮**。通过右键菜单测单个节点时记下 `pinNode` 与它在分组里的位置 `pinIndex`：排序该分组时先把这一行取出，排完其余节点再按原位置插回，结果到达不会把它抽走。该行用主题 `Primary` 14% 的底色、节点名改成 `Primary`，并保持到用户点表头排序或开始新一轮测速为止；`单独测试此节点` 与单选的 `立即测试此节点` 都算单测。
2. **开测不再主动滚到分组顶部**。合并视图刚上线时，`startRounds` 会把当前轮条目分组滚到顶部；对手点的那一行就是一次跳动。现在只有自动推进到下一轮或手动 `上一轮/下一轮` 才滚动定位，起测保持用户当前视口。
3. **折叠窄栏重做**：宽度降到 44px，顶部一个居中的「»」点击区（`Text` + `Hit`，悬停时浅色底），下面逐字竖排「节点来源」。不再画贴边的「展开」按钮，也不再留一条几乎全空的栏。
4. **徽标改成显式尺寸的胶囊**：`Row` 固定高度（字号 + 10）、宽度取 `max(平台测量, 1.35em × 字数) + 12`，文字在剩余宽度里居中；底色用 `MutedForeground` 16%，文字用 `Foreground` 85%，圆角 4。左右留白对称，白底上能明显看出是标签。

## 取舍

- 固定行在用户点表头或重新测速前不参与排序，表头的 ▲/▼ 不再完全代表它；这是为了「盯着一行看结果」的明确取舍，并在交互上给了退出方式。
- 单测高亮会一直保留到下一次排序/测速，不会自动淡出（应用空闲不跑定时器，不做自动动画）。
- 窄栏只剩 32px 宽的「»」点击区，比原来的「展开」按钮小；但整块区域有 hover 反馈，且窄栏不再占空间。
- 中文徽标按 1.35em 兜底会比平台排版左右略宽一点，视觉上更松，但不会再被判截断。

## 影响

- `internal/gui/state.go`：`pinNode/pinIndex`、分组排序时取出/插回、`nodeIndexInGroup`。
- `internal/gui/actions.go`：单测时设置固定、整批测速清除；起测不再滚动。
- `internal/gui/view_speedtest.go`：固定行配色、折叠窄栏、徽标胶囊。
- Driver 测试 43 → 44：新增「单独测试固定原位、点表头解除」；折叠用例改点窄栏的展开命中。
- headless 走查的折叠步骤改为点击「展开节点来源」命中，断言「»」；`layout` 仍 0 problems。
- 绘制仍 0 allocs/op；300 节点 1180×800 基准约 76µs/帧（只画可见行），空闲不绘制。
