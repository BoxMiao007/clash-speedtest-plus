# 订阅按 yaml、base64、再补 flag=meta 规范化

很多订阅打开不是 Clash/Mihomo yaml：有的是整段 base64，有的要在地址上加 `flag=meta` 才返回 yaml。这个参数是机场约定，不是协议标准，所以不总是先改地址。

选源界面和命令行 `-c` 用同一套顺序：原样当 yaml；不行则整段 base64 解码后再当 yaml；还不行且地址里没有 `flag` 参数时，补 `flag=meta` 再请求，并重复前两步。解开后只要 `proxies` 或 `proxy-providers` 里至少有一项就停。不认分享链接，也不认 JSON 订阅。用了补过的地址要告诉用户，不改用户原来写的那条。

多条订阅地址用「逗号加空格」或换行分开，避免把查询串里的逗号切成下一条。
