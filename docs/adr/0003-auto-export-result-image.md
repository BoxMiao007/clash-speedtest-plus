# 测完默认导出结果表图，用 `-no-image` 关掉

> 状态：在 GUI 中恢复（ADR-0018）：每轮结束自动写结果图，设置里「每轮自动保存结果图（PNG）」可关（ADR-0019 补充了标签与说明）；`-no-image` 由该开关取代。

结果表图要便于转发，所以整轮结束默认写 PNG（交互和非交互都写）。脚本、CI、OpenWRT 定时任务并不总想多出图片，因此用 `-no-image` 只关自动导出；TUI 里按 `s` 仍可手动出图。

转发时失败和 N/A 行往往没有用，所以另给 `-image-speed-only`：只从结果图里去掉下载和上传速度都是 0 的行，终端、TSV 和 yaml 仍是全量。快速模式不测速度，这个开关会被忽略并提示一次。
