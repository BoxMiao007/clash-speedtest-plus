# ADR-0026：节点行选中态，条目卡片视觉回退默认

- 状态：已接受
- 日期：2026-10-30
- 关联：[ADR-0021](0021-entry-badge-menu-detail.md)、[ADR-0024](0024-audit-fixes.md)、[规格 0001](../specs/0001-viva-gui.md)

## 背景

试用反馈：左侧条目卡片整卡变成蓝色「选中效果」做错了，要求回退默认；真正需要选中效果的是**节点行**——单击（打开详情）和右键（打开菜单）时都要能看清操作的是哪一行。

## 决策

1. **卡片视觉回退默认**：条目卡片恢复白底 + 普通边框；是否选中只看左上角复选框。整卡点击切换勾选的交互保留（点空白处仍可选中/取消），只是不再给整卡上主题色。
2. **节点行选中态**：新增 `activeNode`。单击行打开详情时设置；右键行打开菜单时设置；关闭详情时清除；点另一行时切换。绘制优先级 `pinNode`（Primary 20%，正在单测）> `activeNode`（Primary 14%，正在查看/操作）> 勾选/测试中（Muted）> 默认。
3. **当前操作行的节点名也变主题色**，和固定行一致，但底色深浅区分。
4. 节点被过滤、重读或删除后，`pruneTransientAnchors` 一并清掉失效的 `activeNode`。
5. 悬停不覆盖选中态：`HoverBackground` 按当前底色加深（固定行 28%、当前行 22%、勾选行 10% 灰），不再固定用 `Muted`，否则鼠标指向时选中行的蓝底会被灰底替换，看起来像选中效果消失。

## 取舍

- 默认所有节点都勾选，行本来就有浅灰底；为了让选中态可见，`activeNode` 用 14% 主题色，比固定行的 20% 浅，避免和「正在单测」混淆。
- 右键菜单关闭后选中态保留，直到下一次点击别的行或关闭详情；没有自动淡出（空闲不跑定时器）。
- 卡片不再有整卡高亮，选中反馈回到复选框；这是用户明确要求的回退。

## 影响

- `internal/gui/view_speedtest.go`：卡片背景/边框回退、行 `activeNode` 配色、`toggleDetail` 同步。
- `internal/gui/contextmenu.go`：打开菜单时设置 `activeNode`。
- `internal/gui/state.go`：`activeNode` 字段与清理。
- Driver 测试 52 → 53：新增「单击/右键标记当前行」。
- 走查 `layout` 仍 0 problems。
