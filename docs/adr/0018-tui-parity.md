# ADR-0018：GUI 补齐 TUI 产物能力（订阅、参数、导出、多轮）

- 状态：已接受
- 日期：2026-10-30
- 关联：[ADR-0016](0016-export-full-profile.md)（导出形态）、[ADR-0017](0017-viva-gui.md)（GUI 架构）、[规格 0001](../specs/0001-viva-gui.md)

## 背景

[ADR-0017](0017-viva-gui.md) 把 TUI/CLI 全部删除，只留「本地文件条目 + 勾选节点 + 测下载速度」的 GUI。第一版规格把这些能力明确列为非目标：远程订阅 URL、Gist/仓库上传、结果图/TSV 导出、IP 归属地改名、阈值过滤、提前停止、多轮队列、暂停/继续、上传测速。

实际交付后试用反馈是「功能缺失过多，无法像 TUI 那样正常使用」。原因很直接：TUI 的核心用途是「拉订阅 → 测速 → 按阈值筛 → 重命名 → 导出可用 profile → 上传」，第一版 GUI 只完成了中间的测速，产物能力全缺，测完等于白测。

## 决策

1. **条目分种类**：`Entry.Kind` 取 `local`（空值同义）或 `subscription`；订阅条目存 `URL`，正文缓存到 `data/subscriptions/<条目 ID>.yaml`。启动只读缓存、不联网；`重新获取` 才重新拉取；地址变更强制重拉；拉取失败保留旧节点。拉取复用 `internal/speedtester.FetchSubscriptionBody`（原样 yaml / base64 / 补 `flag=meta` 重试），UA 来自设置。
2. **设置集中持久化**：`settings.json` 升到版本 2，承载过滤、测速模式、大小、超时、并发、并行、服务器、UA、提前结束、四项阈值、输出模式与路径、结果图、重命名、上传凭据。默认值等于旧 TUI 的 flag 默认值。布尔字段没有「非法值」可判断，因此读取时按「键是否存在」补默认，而不是解析零值再归一化。
3. **按条目分轮**：点「下载速度」时每个选中条目一轮，轮内节点 = 选中 ∩ 过滤命中；一轮测完导出后再推进下一轮；结果视图按轮展示并可前后切换（ADR-0020 起合并进测速视图，换轮改为把对应分组滚到顶部）；≥2 轮全部正常完成后写「合并导出」。
4. **恢复产物包**：`internal/output`（结果图、路径与产物序号、TSV）、`internal/ip`（归属地重命名）、`internal/gist`（上传）从历史提交恢复；新增 `internal/export` 承载导出骨架与阈值过滤。GUI 侧 `export.go` 只做编排：阈值过滤 → 可选重命名 → 写 yaml → 结果图 → 上传。
5. **过滤范围修正**：第一版过滤只影响显示，测速仍测全部勾选节点，与 TUI 的 `-f` 语义不符。现在过滤同时决定显示、测速与导出范围。
6. **后台执行**：订阅拉取、导出（含逐节点 IP 查询与字体渲染）、上传都在 goroutine 里跑，结果经 pending 队列回到窗口线程；窗口线程只做状态更新。导出串行，避免多轮同时写文件。
7. **事件带轮次号**：引擎事件携带轮次；停止/重启后迟到的旧事件按轮次号丢弃，避免上一轮结果写进新一轮。
8. **上传凭据明文**：token 与地址一起存 `data/settings.json`。旧 TUI 每次靠命令行 flag 传入，不落盘；GUI 为了可用性选择持久化，并在设置页明确提示「明文保存、只在本机使用」，不做系统钥匙串集成。

## 取舍

- 明文 token 有泄露风险，换来的是「打开就能用」；已知且写在界面与规格里。
- 导出时按节点查 IP 归属地（`ip-api.com`，每个节点一次请求）；沿用旧 TUI 行为，未加批量/缓存。节点多时导出会慢，但只在导出阶段、且可关闭重命名。
- 订阅缓存可能在用户不点「重新获取」时过期；这是为了启动不联网、空闲不请求而做的显式取舍。
- 结果仍按「整文件重写」持久化（沿用第一版 store），节点很多时每条结果都会重写 `results.json`；不在本次范围内优化。

## 影响

- `internal/gui` 新增 `export.go`、`view_settings.go`；`state.go`/`actions.go`/`engine.go`/`view_results.go` 扩展轮次、排序、详情、设置、提前结束与事件守卫。
- `internal/store`、`internal/speedtester`、`go.mod`（新增 `golang.org/x/image`）有对应改动。
- `docs/specs/0001-viva-gui.md` 的 Out of Scope 收敛到未实现项；README、GLOSSARY、AGENTS 同步。
- 第一版规格里「GUI 只读本地文件、无导出/上传」的表述由本 ADR 取代。
