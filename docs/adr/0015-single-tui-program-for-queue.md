# 一个 TUI 程序托管整个队列的轮视图

多轮测速此前是「每轮一个 tea.Program」：程序退出即丢模型，轮与轮自动推进，用户没有任何回看手段。「轮间切换」（Ctrl+↑/↓ 切换轮界面、在测轮后台继续、切回看实时）在旧结构下无法成立——旧程序退出时，这轮的界面和测试 goroutine 都随之结束。

决定：队列的整个生命周期改由一个 TUI 程序承载，每轮一个视图：Ctrl+↑/↓ 切换，边界轮无操作，单轮队列键位无效；在测轮切走后后台继续测，已完成轮显示最终表；轮与轮自动连续推进不变；Esc（中断本轮＋作废剩余＋回选源）与 Ctrl+C（退出全部）语义原样（见「多轮测速」）。部分终端（tmux 默认配置、linux console）发不出独立的 Ctrl+方向键序列，这些终端上切换不可用但无副作用，不为此加备选键。

备选：只允许切换到已完成轮的只读快照（改动小，但失去实时回看，切换的意义打折）；切走自动暂停（TUI 已有暂停门，可行，但多轮总时长被拉长，与「后台继续」的直觉相反）。代价：队列主循环与 TUI 结构的大改，选源路径与命令行路径统一走新结构，一次性成本高；换来的是此后每一轮的呈现与交互演进都在同一程序内进行。
