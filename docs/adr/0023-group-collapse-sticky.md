# ADR-0023：分组标题可折叠并固定在列表顶部

- 状态：已接受
- 日期：2026-10-30
- 关联：[ADR-0020](0020-merged-test-view.md)（合并视图）、[ADR-0022](0022-pin-rail-badge.md)（固定行与高亮）、[规格 0001](../specs/0001-viva-gui.md)

## 背景

试用截图指出：条目分组标题（`米贝 · 189 个节点 · 已选 189 · 全选/全不选`）滚上去就看不见了；希望这一栏能折叠该组节点，并且固定在列表顶部，滚到下一个订阅条目时自动换成下一组的标题。

## 决策

1. **组标题折叠**：标题左侧加 `▾` / `▸` 箭头（`Text` + `Hit`，悬停浅底），点它折叠/展开该条目的节点行。折叠只影响展示：组内复选框、勾选数、测速/导出范围都不变；组标题追加「已折叠」。折叠状态记在 `entryState.collapsed`，只保留在本次运行内，不写盘。
2. **固定标题浮层**：列表滚到某个组标题之上后，把该组标题画在列表顶部（32px + 1px 分隔线），并自动跟随滚动切换到下一组。判定规则：按 `nodeItems` 顺序取最后一个「标题内容坐标 − 滚动偏移 ≤ 0」的分组；没有这样的分组时正常绘制流内标题。
3. **固定标题下的行做裁剪**：为了避免浮层与滚动内容重叠（指针命中、`layout` 重叠告警），固定标题存在时：
   - 完全落在 33px 内的行不画；
   - 跨过 33px 的行放进一个从 33px 开始、裁剪到行底部的容器里，内容按原滚动位置相对位移后绘制。
   这样固定标题不会盖住可点击的行，命中区也随裁剪收窄；内容本身不移动，所以不会出现跳动。
4. **身份只出现一次**：固定标题显示的那一组，其流内标题跳过绘制；固定标题复用条目自身的 `groupToggle/selectAll/selectNone` 身份，不新增重复按钮。
5. **文案预计算**：折叠箭头与无障碍名称（`折叠 <条目> 的节点` / `展开 <条目> 的节点`）在 `rebuild`/`toggleGroup` 里算好，绘制路径不拼字符串，保持 0 allocs/op。

## 取舍

- 折叠状态不持久化，重启后全部展开；与面板折叠一致。
- 固定标题浮层是「行裁剪 + 覆盖」实现，而不是给列表预留 33px：预留会在标题出现/消失时让内容上下跳 33px；裁剪不会移动内容。代价是跨过顶部的行只显示下半截（本来就该被标题挡住）。
- 固定标题的「全选 / 全不选」和折叠按钮与流内标题共用身份；因为同一组只画一处，不会出现重复命中。
- 滚到下一个条目时标题立即切换，没有「把上一个标题推上去」的动画（Viva 不做空闲动画）。

## 影响

- `internal/gui/state.go`：`entryState.collapsed`、`groupState.collapsed/arrow/toggleLabel`、`buildNodeItems` 折叠分支、`rebuild` 预计算。
- `internal/gui/actions.go`：`toggleGroup`、`groupToggleText`。
- `internal/gui/view_speedtest.go`：固定标题浮层、被覆盖行的裁剪、组标题箭头。
- `internal/gui/ids.go`：`entryIDs.groupToggle`。
- Driver 测试 44 → 46：新增「组标题折叠只隐藏行、不改勾选」「滚到第二组时固定标题跟随」。
- headless 走查增加折叠/展开断言；`layout` 仍 0 problems。
- 绘制仍 0 allocs/op；300 节点 1180×800 约 76µs/帧。
