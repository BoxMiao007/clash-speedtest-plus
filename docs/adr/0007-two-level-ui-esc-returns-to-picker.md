# 选源与测速是两级界面，Esc 返回上一级并保留全部状态

选源界面只负责把源和参数整理成命令行，回车后沿命令行同一条路进入测速界面——两条入口共享一套测速引擎和界面，不另做一套内嵌的测速视图。

测速界面里按 Esc 返回选源界面（详情面板开着时 Esc 仍只关面板，一级一级退）。返回 = 中断本轮：停掉在测节点、取消上传、删半截图，本轮不写任何产物；勾选、订阅地址、全部选项原样保留，改完再回车即重测。命令行直接启动的测速界面没有上一级，Esc 行为保持不变。

由此 main 是一个循环：选源 → 测速 → Esc → 选源。每轮测速器、结果通道、提前结束信号全部重建；退出码只在正常退出路径判定，Esc 返回不算失败。选源界面的退出只有 Ctrl+C，q 和 Esc 都不再退出。
