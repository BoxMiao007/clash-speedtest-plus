# ADR-0024：审查驱动的交互与状态一致性修复

- 状态：已接受
- 日期：2026-10-30
- 关联：[ADR-0020](0020-merged-test-view.md)、[ADR-0022](0022-pin-rail-badge.md)、[ADR-0023](0023-group-collapse-sticky.md)、[规格 0001](../specs/0001-viva-gui.md)

## 背景

对合并视图做了一次只读审查（测速视图交互 + 状态/轮次/导出两条线），发现一批真实问题：条目卡片只有复选框能点、没有选中态；整卡命中会让禁用的「读取缓存」点击穿透成取消勾选；最小面板宽度下按钮溢出、标题与徽标被压字；多选右键「立即测试所选节点」绕过过滤器；表头与行的名字列收缩基准不同导致窄窗口列错位；详情面板是打开时的快照且可能画到卡片外；测速中切轮会把正在跑的轮次账本弄乱、误导出空配置；手动导出挡住某一轮自动导出时该轮永不导出；停止后行永久「测试中」；拉取中改订阅地址会写回旧地址的正文。本文记录修复口径。

## 决策

1. **条目卡片整卡可点**：点卡片空白处切换该条目勾选，选中时用主题色 6% 淡底 + 45% 主题色边框；卡片上的按钮仍是独立命中，优先于整卡。订阅拉取中（按钮禁用）卡片不再接管点击，避免「点禁用按钮 → 取消勾选」。
2. **最小面板宽度 220 → 260**：220px 下标题和 4 个动作按钮放不下；同时把动作按钮拆成两行（读取/重新获取、编辑/删除），给标题与路径徽标 `MinWidth`/`Shrink(0)`，不再出现压字。
3. **表头与行共用名字列基准**：两边都 `Basis(0) + Grow(1)`，数值列固定宽，窄窗口下不再错位。
4. **右键测试也遵守过滤**：`startNodesTest` 按 `match` 过滤；全部被过滤时提示「当前过滤条件下没有可测试的节点」。
5. **详情跟随结果**：详情文案在 `refreshNodeDisplay` 末尾重算（放在展示字段更新之后）；面板加 `Clip`，超长文案不再画出卡片。
6. **轮次账本与视图解耦**：完成、提前结束、自动推进只认 `run.round`（新增 `runRound()`），`switchRound` 只改用户正在看的 `roundIndex`。测速中切轮不再把被翻到的轮误标完成或导出空配置。
7. **挂起导出有人消费**：手动导出结束（`roundRef == nil`）时若存在 `pendingExport` 且队列仍在，补启动该轮导出；停止时把 `phaseTesting` 的行也复位，避免永久「测试中」。
8. **订阅拉取代次**：每条目 `fetchSeq`，地址改动可开新请求，旧代次结果按 seq 丢弃；拉取客户端加 60s 超时；窗口关闭后 `enqueue` 直接丢弃。
9. **菜单目标重新解析**：菜单激活时按节点 key 从当前模型重新找，后台重读后不会对已消失节点操作。
10. **悬空锚点清理**：排序后校验详情与固定行是否仍在可见分组里，不在就清掉。
11. **窗口拉高不留白**：列表虚拟化用窗口高度作绘制下限（超出列表的部分由 Clip 裁掉），不再依赖「下一帧」补画。
12. **折叠走 AfterPaint**：组标题箭头不在遍历 `nodeItems` 的绘制回合里直接重建列表。

## 取舍

- 卡片选中底色按主题色 6% 渲染，视觉上比行选中更醒目；默认全部条目选中时左栏会偏蓝，这是「选中态必须明显」的直接结果。
- 最小宽度提高 40px，窄屏下左栏占位更多；换来标题与按钮不再被裁。
- 用窗口高度做绘制下限会让每帧多画几行（被 Clip 裁掉），300 节点基准从约 76µs 升到约 102µs，仍为 0 allocs/op，空闲不绘制。
- 拉取超时固定 60s，不跟设置项走；需要更短/更长时再抽成配置。

## 影响

- `view_speedtest.go`：卡片命中/选中态、两行按钮、名字列 Basis、详情刷新与 Clip、组标题 AfterPaint、绘制下限。
- `actions.go`：`runRound()` 口径、advanceRound 基准、pendingExport 消费、`startNodesTest` 过滤、停止相位复位、菜单解析、enqueue 关闭守卫。
- `state.go`：`fetchSeq/fetchURL`、`nodeByKey`、`pruneTransientAnchors`、`applySort` 收尾、`refreshNodeDisplay` 顺序。
- `ids.go`：`entryIDs.card/emptyRead`。
- `internal/speedtester`：拉取客户端 60s 超时。
- Driver 测试 46 → 51：卡片点击、过滤后右键测试、详情刷新、隐藏节点清理、运行中切轮。
- 走查仍 `PASS`、`layout` 0 problems；基准 0 allocs/op（约 102µs/帧）。
