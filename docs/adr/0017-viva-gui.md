# 用 Viva GUI 取代 TUI 与 CLI，数据落在程序目录

旧程序只有终端界面：不带参数且 stdout 是终端时进 `picker/` 选源，选了以后进 `tui/` 测速；带参数走命令行。桌面用户没有可双击的界面，条目（测速源）每次都要重新选，过滤条件、上次测速结果也留不下来。

决定：

1. **只保留 GUI**。根入口改为 Viva 单窗口应用；`picker/`、`tui/`、`output/`、`gist/`、`ip/` 与命令行 flag 逻辑全部删除。测速引擎与配置解析不重写：`speedtester/` 迁到 `internal/speedtester/`，GUI 通过窄接口 `gui.Runner` 调用 `New` + `TestProxiesUntil`，进度回调经 `app.Invalidator` 回到窗口线程。
2. **两个视图**。`节点选择` 按条目分组、复选框选择；`下载速度` 展示结果并按下载速度实时重排。点「下载速度」按钮开始测速并自动切换。行身份由 `ui.Tree` 中的「条目 ID + 节点稳定身份」在数据加载时注册，不按列表位置编号，重排后焦点/命中不漂移。
3. **数据目录**。条目、过滤预设、设置、节点测速结果统一写 `<程序目录>/data/*.json`，原子替换；不写主目录、AppData 或注册表。数据目录不可写时在窗口内明确报错并禁用持久化，不换位置、不散落。程序目录由 `os.Executable()` 决定，与旧「产物写到程序目录」的 ADR-0004 同一口径。
4. **软 / 硬路径**。条目可以存相对程序目录的软路径（`/` 分隔，跨平台）或绝对硬路径；程序目录内的绝对路径保存时自动转软路径。拷贝整个程序目录即可迁移。
5. **简化过滤 + 正则 + 预设**。默认关键词模式：空格分词、`!` 排除、`*`/`?` 通配、与/或可选、大小写不敏感；切到高级模式保留完整 Go 正则。过滤条件（含模式与组合方式）可命名保存为预设，跨条目通用。
6. **右键菜单**。单层平铺，单节点与多选语境用不同措辞区分；命中判定用 `canvas.PointerOn` + `components.BeginContextMenu`，菜单项点击在声明处用 `canvas.Clicked` 处理。

后果：没有终端/管道模式，旧的 `-f`、`-o`、`-early-stop`、gist/仓库上传、结果表图、IP 改名等入口一并消失（见规格 11 节 Out of Scope）。Windows 发布二进制用 `-H=windowsgui`，不再有控制台窗口。数据目录不可用、文件读取失败等窗口内错误有对话框/行内提示；窗口与图形后端初始化失败时还没有界面可用，只能写 stderr/系统日志，无法在窗口内提示。macOS 的 Viva 后端依赖 cgo，发布矩阵只含 Windows/Linux（amd64、arm64），macOS 需在 Mac 上 `CGO_ENABLED=1` 从源码构建；386/arm32 不再发布。`proxy-providers` 的内核缓存通过 `constant.SetHomeDir` 重定向到 `<程序目录>/data/mihomo/`，不写用户主目录。新增依赖只有 Viva，体积/启动/空闲内存测量记录在交付说明里。

备选：保留 CLI 与 GUI 双入口（`gui` 与旧 `main` 并存，构建目标与依赖翻倍，且需求明确要求移除）；用 WebView（违反 Viva 无 Web 技术约束）；把数据放 `os.UserConfigDir()`（违反「目录拷贝即迁移」）。
